# Bundled fonts

These Latin-subset WOFF2 files are self-hosted so builds and reading sessions do not need to contact Google Fonts.

| File | Family | Weight | Style |
| --- | --- | --- | --- |
| `google-sans-flex-latin.woff2` | Google Sans Flex | 100–1000 (variable) | Normal |
| `lora-latin.woff2` | Lora | 400–700 (variable) | Normal |
| `architects-daughter-latin.woff2` | Architects Daughter | 400 | Normal |
| `ibm-plex-mono-400-latin.woff2` | IBM Plex Mono | 400 | Normal |
| `ibm-plex-mono-500-latin.woff2` | IBM Plex Mono | 500 | Normal |

Downloaded from the official Google Fonts stylesheet and `fonts.gstatic.com` assets on 2026-10-03:

https://fonts.googleapis.com/css2?family=Architects+Daughter&family=Google+Sans+Flex:wght@100..1000&family=IBM+Plex+Mono:wght@400;500&family=Lora:wght@400..700&display=swap

Each family is licensed under SIL Open Font License 1.1. The matching `*-OFL.txt` files come from the official [Google Fonts repository](https://github.com/google/fonts/tree/main/ofl).
